Agent CSI Feature Completion
============================

Goal
Finish the remaining agent-side CSI functionality so storage support is not limited to the current narrow compatibility set.

Current evidence
- README.md still marks "Storage (CSI)" as unfinished.
- tugboat-agent/src/reconciler/volume.rs validates both Block and Filesystem modes and enforces compatibility between PVC and PV.
- tugboat-agent/src/csi.rs and the reconciler now accept node_publish_secret_ref and node_stage_secret_ref and load secret data for node-side publish/stage flows.
- Controller-side secret refs and controller-only capabilities (controller_publish_secret_ref, controller_expand_secret_ref, node_expand_secret_ref) are still rejected and not implemented.
- NodeStage/NodeUnstage capabilities and robust node-side recovery (recreating mounts after agent restart) remain incomplete.

Important scope note
- Dynamic PVC provisioning and PV cleanup already exist in tugboat-controller-manager.
- This TODO is focused on completing node-side attach, publish, and recovery behavior in tugboat-agent; controller-side controller_* flows are a separate concern.

What to implement
- Implement NodeStageVolume/NodeUnstageVolume flows when drivers require staging, including creating stage and target paths and idempotent stage/publish operations.
- Pass CSI secret references from PersistentVolume sources into the node publish and stage calls where required (note: controller-side secrets are separate and may remain out of scope for the node implementation).
- Add node-side volume expansion support if decided in scope, with status reporting.
- Improve agent restart recovery to rediscover and clean up published mounts and avoid stale state files.
- Document the supported CSI capability matrix and driver compatibility so users understand which drivers and access modes are supported.

Implementation surfaces
- tugboat-agent/src/reconciler/volume.rs
- tugboat-agent/src/csi.rs
- tugboat-agent/src/reconciler/ops/add.rs
- tugboat-agent/src/reconciler/ops/modify.rs
- tugboat-agent/src/reconciler/ops/delete.rs
- tugboat-csi-operator/src/ (add NodeStageVolumeRequest/NodeUnstageVolumeRequest gRPC wrappers)
- tugboat-vm-runtime-interface/src/

Acceptance criteria
- Both Block and Filesystem volumes are attachable when the CSI driver supports them.
- Node-stage and node-publish flows work for drivers requiring staging.
- Secret-backed node publish/stage flows work for supported drivers.
- Agent restart recovery can rediscover and clean up published volumes without orphaning state.
- Integration tests exist for at least one happy path and one cleanup/recovery path.
