# Fleet コントローラー結合テスト

## 概要

Fleet コントローラーが API サーバーと連携し、Ship のグルーピングと
プライベートネットワークの管理を正しく行うフローを検証する。

## 前提

- API サーバーとコントローラーマネージャーが起動していること

## テストシナリオ

### シナリオ 1: Fleet の作成と Ship テンプレート

1. Namespace を作成
2. Fleet を作成（複数の Ship テンプレートを含む）
3. Fleet に基づいて ReplicaSet/Ship が作成されることを確認
4. 作成された Ship のラベルに Fleet の情報が含まれること

### シナリオ 2: Fleet のネットワーク設定

1. Fleet を作成
2. Fleet に関連する NetworkClass が作成されることを確認（実装に依存）
3. Fleet 内の Ship が同一ネットワークに属する設定になっていること

### シナリオ 3: Fleet の更新

1. Fleet を作成し Ship が作られるのを待つ
2. Fleet の spec を更新
3. 変更が関連リソースに反映されることを確認

### シナリオ 4: Fleet の削除

1. Fleet を作成し関連リソースが作られるのを待つ
2. Fleet を削除
3. 関連する Ship や ReplicaSet も削除されることを確認

## 完了条件

- Fleet によるリソースグルーピングがテストされていること
- Fleet 削除時のカスケード動作がテストされていること
- `cargo test` が通ること
