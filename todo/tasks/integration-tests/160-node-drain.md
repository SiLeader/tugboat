# Node ドレインの結合テスト

## 概要

Node のドレイン操作が正しく動作することを検証する。
ドレインにより Node 上の Ship が退避されることを確認する。

## 前提

- API サーバーとスケジューラーが起動していること
- 複数の Node が登録されていること

## テストシナリオ

### シナリオ 1: Node ドレインの実行

1. Node `drain-node` と `other-node` を作成
2. `drain-node` 上にスケジュールされた Ship を作成
3. `POST /api/v1/nodes/drain-node/drain`（または対応する API）でドレインを実行
4. Ship が `drain-node` から退避されることを確認

### シナリオ 2: ドレイン後の新規スケジュール禁止

1. Node をドレインする
2. 新しい Ship を作成
3. ドレイン済み Node にスケジュールされないことを確認

## 完了条件

- Node ドレインによる Ship 退避がテストされていること
- ドレイン後のスケジュール禁止がテストされていること
- `cargo test` が通ること
